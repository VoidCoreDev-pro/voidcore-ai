# VOIDCORE AI

**The Ultimate AI Terminal Experience**

VOIDCORE AI is a powerful command-line AI application that brings 40 AI profiles into one elegant terminal interface.

Experience real-time AI conversations, a premium terminal design, animated startup sequences, and an interactive model selection system.

## Features

* 40 selectable AI profiles
* 6 AI provider categories
* Real-time AI conversations
* Premium black and green terminal interface
* Animated startup and loading sequences
* Interactive model selection
* Built-in terminal commands
* Windows CMD support
* No personal API key required for users

## Installation

### Requirements

* Windows 10 or Windows 11
* Python 3.11 or newer
* Internet connection

### Step 1 — Download

Download this repository as a ZIP file and extract it.

### Step 2 — Open CMD

Open Command Prompt inside the extracted VOIDCORE AI folder.

### Step 3 — Install dependencies

```cmd
py -m pip install -r requirements.txt
```

### Step 4 — Launch VOIDCORE AI

```cmd
py main.py
```

## Terminal Commands

| Command | Description                    |
| ------- | ------------------------------ |
| /help   | Display available commands     |
| /models | Browse all AI profiles         |
| /model  | Change the selected AI profile |
| /clear  | Clear the terminal             |
| /exit   | Close VOIDCORE AI              |

## AI Infrastructure

VOIDCORE AI uses a centralized AI backend to process conversations.

Users do not need to provide their own API keys.

The application connects to the VOIDCORE AI server, which securely manages API credentials and processes AI requests.


## Security

API credentials are stored on the server and are never included in the public GitHub repository.

The backend uses request limits to protect the service from excessive usage.
